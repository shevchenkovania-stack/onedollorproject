# SEO.md — семантическое ядро и обвязка Telegram (живой документ)

> Цель: чтобы нас находили в поиске, когда человек ищет «однушку в Кишинёве» (RU) или
> «chirie 1 cameră Chișinău» (RO). **Что реально индексирует поиск Telegram: название
> поверхности + @username + описание. Текст постов — нет.** Google индексирует публичные
> каналы через `t.me/<handle>` (и превью-страницу `t.me/s/<handle>`).
> Инструмент: `deploy/seo_seeds.py` — идемпотентен, один источник текстов.

### RO
| Кластер | Запросы | Поверхность |
|---|---|---|
| ядро | chirie chișinău, chirie 1 cameră, garsonieră de închiriat | бот (имя lang=ro, long desc), S3 |

Формула заголовка: `ключ · ключ · Geo — дифференциатор`, ключи в начале, ≤ 60 симв.
Дифференциатор везде один и тот же (и он честный): **однушки, от хозяина, без комиссии** —
в этом наше отличие от 999.md/Advert (они — свалка типов жилья и посредников).

## 3. Жёсткое ограничение платформы (проверено на проде, а не по догадке)

**Бот не может создать канал.** В Bot API/aiogram 3.31 нет `CreateChatPublisher` и нет
`AddChatMember` — канал создаёт только аккаунт человека. Поэтому обвязка делится на две части:
скрипт делает всё, что умеет API (имена, описания, названия, welcome, закреп, трекинг),
а человек делает то, чего API не умеет — 4 канала по 3 тапа.

## 4. Что делает человек (10 минут, потом всё автоматом)

Для каждого из четырёх кластеров:
1. Telegram → Новый канал → название любое (скрипт переименует сам).
2. Управление каналом → Администраторы → добавить `@gaseste_casa_bot`, право «Публиковать сообщения».
3. Тип канала → Публичный → дать recommended @handle.
4. Сообщить мне handle (или запустить): `/opt/imobiliare/venv/bin/python /tmp/seo_seeds.py s1=@odnushki_md`

| Ключ | Title (ставит скрипт) | @handle |
|---|---|---|
| s1 | Однушки в Кишинёве · Аренда без комиссии | `@odnushki_md` |
| s2 | Снять Квартиру в Кишинёве · Без Посредников | `@chirie_kvartire_md` |
| s3 | Chirie 1 Cameră Chișinău · Garsonieră Direct Proprietar | `@chirie_1camera_chisinau` |
| s4 | Chirie Botanica · Râșcani · Buiucani pe Sector | `@chirie_sector_chisinau` |

После регистрации скрипт сам: назовёт, опишет (≤255), выложит **один** welcome-пост с
отслеживаемой кнопкой и закрепить его. Повторный запуск правит на месте, дублей не создаёт
(id'ы в `/opt/imobiliare/data/seo_channels.json`).

## 5. Трекинг и проверка

Каждая поверхность ведёт на `t.me/gaseste_casa_bot?start=seo_<key>` → `events.start.meta`.

```sql
SELECT substr(meta,1,12) src, count(*) n, count(distinct user_id) uniq
FROM events WHERE name='start' AND meta LIKE 'seo_%' GROUP BY src ORDER BY n DESC;
```

Общий поток — `/traffic` и утренний дайджест. Проверка выдачи: через 1–3 дня после публикации
искать в Telegram «однушки кишинев», «chirie 1 camera chisinau», «odnushki» и смотреть позицию;
проиграл — правим title/desc в `seo_seeds.py` (единственный источник) и перезапускаем.

## 6. Честно: чего SEO в Telegram не даст

- Новому каналу без подписчиков тяжело: ранг зависит от числа подписчиков и активности. Это
  пассивная сеть, а не воронка. **Главный канал привлечения остаётся outreach + шаринг карточек.**
- Доска сейчас пуста (listings = 0): трафик, пришедший по ключу, попадёт на ноль и уйдёт.
  SEO имеет смысл в связке «сначала первые реальные объявления → потом обвязка». Обвязку сделали —
  наполнение по-прежнему блокер №1 (MISSION).
- @username бота (`gaseste_casa_bot`) не меняется — deep-ссылки остаются на нём.
- Больше 4 поверхностей этого семейства = шум и риск выглядеть спамом; расширение ядра — только
  через эту таблицу и этот скрипт.
