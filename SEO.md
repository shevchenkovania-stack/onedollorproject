# SEO.md — семантическое ядро и обвязка Telegram (живой документ)

> Цель: чтобы нас находили в поиске, когда человек ищет «однушку в Кишинёве» (RU) или
> «chirie 1 cameră Chișinău» (RO). **Что реально индексирует поиск Telegram: название
> поверхности + @username + описание. Текст постов — нет.** Google индексирует публичные
> каналы через `t.me/<handle>` (и превью-страницу `t.me/s/<handle>`).
> Инструмент: `deploy/seo_seeds.py` — идемпотентен, один источник текстов.

в этом наше отличие от 999.md/Advert (они — свалка типов жилья и посредников).

## 3. Жёсткое ограничение платформы (проверено на проде, а не по догадке)

**Бот не может создать канал.** В Bot API/aiogram 3.31 нет `CreateChatPublisher` и нет
`AddChatMember` — канал создаёт только аккаунт человека. Поэтому обвязка делится на две части:
скрипт делает всё, что умеет API (имена, описания, названия, welcome, закреп, трекинг),
а человек создаёт недостающие поверхности (3 тапа на канал). Уже публичный `@gaseste_casa`
ручных действий не требует — он подключён к скрипту как кластер `board` через `CHANNEL_ID`.

## 4. Сателлиты: что делает человек (Bot API не создаёт каналы)

Для каждого из трёх оставшихся кластеров:
1. Telegram → Новый канал → название любое (скрипт переименует сам).
2. Управление каналом → Администраторы → добавить `@gaseste_casa_bot`, право «Публиковать сообщения».
3. Тип канала → Публичный → дать recommended @handle.
4. Сообщить мне handle (или запустить): `/opt/imobiliare/venv/bin/python /tmp/seo_seeds.py rent=@chirie_kvartire_md`

| Ключ | Title (ставит скрипт) | @handle |
|---|---|---|
| rent | Снять Квартиру в Кишинёве · Без Посредников | `@chirie_kvartire_md` |
| ro | Chirie 1 Cameră Chișinău · Garsonieră Direct Proprietar | `@chirie_1camera_chisinau` |
| sector | Chirie Botanica · Râșcani · Buiucani pe Sector | `@chirie_sector_chisinau` |

После регистрации скрипт сам: назовёт, опишет (≤255), выложит **один** welcome-пост с
отслеживаемой кнопкой и закрепляет его. Повторный запуск правит на месте, дублей не создаёт
(id'ы в `/opt/imobiliare/data/seo_channels.json`). Ключ `board` уже заведен — это сам
`@gaseste_casa`, он берётся из `CHANNEL_ID` в `.env`, вручную его регистрировать не надо.

## 5. Трекинг и проверка

Каждая поверхность ведёт на `t.me/gaseste_casa_bot?start=seo_<key>` → `events.start.meta`.

```sql
SELECT substr(meta,1,12) src, count(*) n, count(distinct user_id) uniq
FROM events WHERE name='start' AND meta LIKE 'seo_%' GROUP BY src ORDER BY n DESC;
```

Общий поток — `/traffic` и утренний дайджест. Проверка выдачи: через 1–3 дня после публикации
искать в Telegram «однушки кишинев», «chirie 1 camera chisinau», «odnushki» и смотреть позицию;
проиграл — правим title/desc в `seo_seeds.py` (единственный источник) и перезапускаем.

## 6. Один источник правды (важно, чтобы не сбивать ядро)

Раньше название/описание канала и бота писали **четыре** скрипта (`rename.py`, `seo_channel.py`,
`polish_channel.py`, `pin_roles.py`) и переписывали друг друга. С 23.10:

- `seo_seeds.py` — **единственный** источник всех индексируемых имён и описаний (бот + каналы);
- `seo_channel.py` — только три «как работает» поста витрины;
- `pin_roles.py` — только закреплённая навигация;
- `rename.py` и `polish_channel.py` удалены (их текст противоречил клину «только однушки»);
- `apply_channel_on.sh` / `verify_channel.sh` — включить канал и проверить его состояние.

## 7. Честно: чего SEO в Telegram не даст

- Новому каналу без подписчиков тяжело: ранг зависит от числа подписчиков и активности. Это
  пассивная сеть, а не воронка. **Главный канал привлечения остаётся outreach + шаринг карточек.**
- Доска заполнена **витринными ДЕМО-однушками** (10 карточек, метка «🧪 ДЕМО», зарезервированные
  номера `+373 79 900 0NN`): это честно по отношению к пришедшему и легально (нет чужих фото),
  но первая настоящая сдача всё равно за владельцем — ДЕМО не конвертится в деньги.
- Из старого канала бот **не смог удалить** 24 поста (ids: 1, 4, 5, 9, 11, 13, 15, 20, 44,
  46…60) — Telegram запрещает боту-админу удалять чужие сообщения. Это посты Acces Imobil,
  то есть та же ToS/-IS экспозиция, из-за которой канал и прятали 17.10. Снятие — одно из двух:
  выдать боту право «Управление сообщениями» и перезапустить `apply_channel_on.sh`, либо
  удалить эти 24 поста руками из аккаунта владельца.
- @username бота (`gaseste_casa_bot`) не меняется — deep-ссылки остаются на нём.
- Больше 4 поверхностей этого семейства = шум и риск выглядеть спамом; расширение ядра — только
  через эту таблицу и этот скрипт.
