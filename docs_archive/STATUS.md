# STATUS — состояние проекта на 2026-10-11 (поздний вечер)

Миссия: `MISSION.md` — первый реальный платёж от клиента в Молдове.
Проект: маркетплейс аренды/продажи жилья в Кишинёве. Telegram-бот + Mini App, бесплатные объявления, платный Boost.
Связанная документация: `GROWTH.md` — наполнение доски, тексты для рассылки, цены, метрики, почему именно эти способы оплаты.
**`RUNBOOK.md` — полное описание проекта: архитектура, ENV, схема БД, callback-пространство, деплой с нуля,
бэкап/откат, восстановление «если всё пропало».** Читать, когда код или сервер неизвестны.

Стек фактически: **Python 3.12 / aiogram 3 / SQLite (aiosqlite) / aiohttp Mini App / systemd / nginx + certbot (установлены, ждут домен)**.
Публичный HTTPS работает через **cloudflared quick tunnel** (`deploy/apply_tunnel.sh`, запущен на проде 11.10).
Доступы к серверу: `ACCESS.md` (не в git).
