## AI (шаг 2 — после того, как базовый путь «человек добавил объявление» выверен)
Граница из MISSION не меняется: AI делает **неструктурированное → структурированное**, деньги/БД/платежи/
конечные автоматы остаются детерминированным кодом. AI **извлекает, а не сочиняет**: ни одного факта,
которого нет в словах автора; карточка показывается человеку на подтверждение до публикации.
- [ ] **#1 «Объявление одним сообщением»**: человек кидает текст + фото → `ai.py` (OpenAI-совместимый API,
      дешёвая flash-модель) вытаскивает deal/ptype/rooms/district/price/floor/description → мастер подачи
      стартует предзаполненным → один тап «Опубликовать». 11 шагов превращаются в 2. Провайдер-ключ =
      единственное, что нужно от человека.
- [ ] **#2 Умный поиск текстом**: «хочу двушку в центре до 400» → парс в фильтры БД (детерминированный
      SQL), результаты — только реальные строки, без генерации. Пустая выдача = честное «нет таких» + CTA.
- [ ] **#3 Полировка описания**: черновик из кривого текста в 2–3 нормальных предложения без выдуманных
      фактов, автор может отклонить.
